# Traefik Strapi

Path: `infra/traefik-strapi`

This directory hosts a small containerized stack for Traefik and Strapi-related experimentation.

## Scope

The visible files include:

- a Traefik-focused `docker-compose.yml`,
- a helper startup script,
- and a nested `strapi/` tree with Docker and `npx` scaffolding.

## Current interpretation

This is an infrastructure sandbox for reverse proxy and CMS composition rather than a finished internal platform.
