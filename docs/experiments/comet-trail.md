# Comet Trail

Path: `experiments/comet-trail`

`comet-trail` is a tiny visual experiment rather than an application or framework.

## Observable scope

The directory contains HTML files for pulse or trail animation variants:

- `comet-trail-pulse-animation.html`
- `comet-trail-pulse-animation-2.html`

## Current interpretation

This appears to be a self-contained motion or interaction study that could inform later frontend work, but it is not a product surface on its own.
