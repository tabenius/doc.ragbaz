# TanStack Start Basic Cloudflare

Path: `experiments/tanstack-start-basic-cloudflare`

This project is a framework example rather than a custom application.

## Scope

The upstream README presents it as:

- TanStack Start,
- Cloudflare Workers deployment,
- SSR on the edge,
- access to Cloudflare bindings.

## Current role

This is best treated as a reference implementation or learning scaffold for evaluating TanStack Start as an alternative app platform.
