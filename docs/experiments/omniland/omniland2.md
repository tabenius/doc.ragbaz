# Omniland2

Path: `experiments/omniland/omniland2`

`omniland2` is the most substantial Omniland experiment.

## Scope

The package manifest and directory structure suggest:

- Next.js 16 plus OpenNext/Cloudflare deployment,
- content sources and migrations,
- tests via Node and Playwright,
- editor-related dependencies similar to `my-editor`,
- and a broader sandbox or prototype environment.

## Current interpretation

This looks like a serious prototype for a Cloudflare-deployable editor or content application, possibly the most likely Omniland project to graduate into a real product if the direction becomes clearer.
