# Shipwrecks.se

Path: `products/shipwrecks.se`

`shipwrecks.se` is a vertical data-and-exploration application focused on Swedish shipwrecks.

## Scope

Across the README, project documentation, and package manifest, the application includes:

- a React frontend,
- mapping via Leaflet,
- PostgreSQL-backed data,
- notes and media,
- imports from spreadsheet-like formats,
- user auth,
- Stripe integration,
- and a Node/Express backend.

## Current interpretation

This is already broader than a simple map demo. It has enough product surface to become a niche subscription or organization-facing application if deployed and tightened.
