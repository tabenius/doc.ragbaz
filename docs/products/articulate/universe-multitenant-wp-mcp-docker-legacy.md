# Universe Legacy Docker Platform

Path: `products/articulate/universe/multitenant-wp-mcp-docker-legacy`

This repository is explicitly labeled legacy in the workspace docs.

## Scope

It contains the older combined stack of:

- Next.js web frontend,
- Python MCP server,
- WordPress and database services,
- Dockerized local platform setup,
- and associated docs and templates.

## Current role

The codebase is useful for compatibility, migration, and design archaeology. It should not be confused with the active storefront path in `storefront/`.
