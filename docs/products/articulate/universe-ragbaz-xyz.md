# Universe Ragbaz.xyz

Path: `products/articulate/universe/ragbaz.xyz`

`ragbaz.xyz` is the companion Cloudflare Worker service inside the Universe workspace.

## Scope

The workspace README describes it as handling:

- plugin handshake endpoints,
- tenant previews,
- telemetry surfaces,
- and `/api/v1/*`-style service endpoints.

## Current role

This project is not the storefront itself. It is the edge or service companion that helps the broader Articulate ecosystem coordinate plugin connections and auxiliary platform behavior.
