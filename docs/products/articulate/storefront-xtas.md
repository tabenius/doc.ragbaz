# Storefront XTAS

Path: `products/articulate/storefront-xtas`

`storefront-xtas` is another modern storefront codebase for the same general Articulate business story: headless WordPress plus commerce.

## Scope

The project contains:

- a Next.js storefront application,
- `packages/` for related plugin work,
- `docs/` with design or implementation plans,
- frontend assets under `src/`, `public/`, and `css/`,
- and tests and helper scripts.

## Current interpretation

This appears to overlap significantly with `articulate/universe/main`. The repo still matters because it may contain useful UX or integration work, but it is hard to treat as canonical while `universe/main` is also active.

## Documentation note

This page treats `storefront-xtas` as a parallel or predecessor storefront implementation, not as the current source of truth.
