# Storefront

Path: `products/articulate/universe/storefront`

`storefront/` is the active storefront and admin application inside the Universe workspace. It was renamed after `storefront-xtas` was archived and this worktree was selected as the canonical Articulate storefront.

## Scope

The README and package manifest show:

- Next.js 16 on the App Router,
- OpenNext for Cloudflare Workers,
- Stripe integration,
- WordPress GraphQL content access,
- workspace packages including the WordPress companion plugin,
- admin routes and components,
- storage integrations for uploads and generated assets.

## Current role

This is the current commercial frontend for the Articulate family.
