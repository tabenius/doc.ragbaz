# WP AI

Path: `products/articulate/wp-ai`

`wp-ai` is one of the least defined directories in the Articulate family.

## Observable scope

The directory currently exposes only a skeleton:

- `docker/`,
- `templates/`,
- `tenants/`.

There is no strong runtime entrypoint or product README at the root.

## Current interpretation

This looks like an early concept for multi-tenant WordPress plus AI positioning, not a finished or even clearly scoped product.

## Documentation stance

Until a concrete brief exists, this project should be read as:

- a concept placeholder,
- a future tenancy or provisioning lane,
- or a candidate to move into `experiments/`.
