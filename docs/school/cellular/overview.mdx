# Mobile Subscriber-Identity Security

in SMS/MMS, covert transport channels that bypass an on-device VPN, and the
DFIR playbook down to carrier records — is maintained as a module of the
**RAGBAZ school**, together with the Android compromise-assessment forensics
course and its gated lab assets.
