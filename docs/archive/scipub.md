# SciPub

Path: `products/scipub`

`scipub` is the least defined product directory under `products/`.

## Scope

The visible structure shows:

- a Vite/React application under `scipub-app/`,
- a Cloudflare Worker entrypoint,
- and HTML artifacts or experiments in `public/`.

## Current interpretation

The app source and README still look very close to starter-template state. There may be a future scientific publishing or review workflow here, but the buyer, workflow, and problem are not yet documented.

## Documentation stance

This project remains in `products/`, but it behaves more like an experiment until its scope is explicitly named.
