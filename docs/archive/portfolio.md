# Portfolio

Path: `products/portfolio`

`portfolio` is a frontend application intended to present work and identity rather than sell a standalone product directly.

## Scope

The current project structure indicates:

- a Vite/React/Tailwind stack,
- tests via Vitest,
- a large set of UI dependencies,
- and a README that still reads like a generic Lovable-generated starter.

## Current interpretation

This repository should be treated as a business-development asset for the rest of the portfolio. Right now the codebase is more mature than the narrative content.

## Documentation note

The most important missing layer here is not more frontend plumbing. It is product storytelling: flagship case studies, proof, screenshots, and clear contact pathways.
