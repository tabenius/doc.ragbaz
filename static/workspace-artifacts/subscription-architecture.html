    L --> M[Onboarding wizard unlocked\nin mailguard-ui]

    N --> O([Subscriber active — mail flowing])

5. Tenant Lifecycle State Machine

State transitions for a single subscription from creation to termination.

stateDiagram-v2
    [*] --> Checkout : visitor selects plan

    Checkout --> Provisioning : Stripe payment_intent.succeeded
    Checkout --> [*] : payment failed / abandoned

    Provisioning --> Active : health check passes + onboarding complete
    Provisioning --> ProvisioningFailed : timeout or image pull error

    ProvisioningFailed --> Provisioning : operator retries

    Active --> Suspended : payment missed — grace period starts
    Active --> Upgrading : plan change or add-on purchase
    Active --> Cancelling : subscriber requests cancellation

    Upgrading --> Active : new stack healthy
    Upgrading --> Active : config hot-reload — no restart

    Suspended --> Active : payment recovered within grace period
    Suspended --> Terminating : grace period expired

    Cancelling --> Terminating : data export window elapsed

    Terminating --> [*] : containers stopped, volumes archived, tenant record closed
