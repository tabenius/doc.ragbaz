# Theme Editor MDX Components

The standalone `@ragbaz/bazweave-theme` experiment exports MDX-ready theme
editor components for documentation systems such as Docusaurus. It depends on
`@ragbaz/bazweave-font` for shared font specimens, so theme examples can show
the same type vocabulary as the font chooser without copying component code.

The source templates come from the Articulate universe storefront style editor:
role-based typography presets for Display, Heading, Subheading, Body, and
Button text. The MDX layer keeps those presets portable and interactive.

## Import Surface

```jsx
import {
  ThemeEditorTemplateDeck,
  ThemeFontDependencyExample,
  ThemeMdxExample,
  ThemeRoleMatrix,
  ThemeSpecimen,
} from '@ragbaz/bazweave-theme/mdx';
```
